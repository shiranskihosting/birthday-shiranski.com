# ברכות יום הולדת – שירנסקי מארח

כתובת: https://birthday.shiranski.com/

דף אחד לכל ימי ההולדת. השם והתאריכים מגיעים מהקישור:
`https://birthday.shiranski.com/?n=דנה כהן&s=20261011&t=20261111`
- `n` – שם מלא, כמו בגיליון המעקב (בכרטיס מופיע רק השם הפרטי)
- `s` – תאריך שליחת ההודעה (נרשם בגיליון המעקב)
- `t` – בתוקף עד

מעקב: כל כניסה ולחיצה על "רוצה לתאם ערב" מעדכנות שורה אחת לכל לקוח בגיליון "מעקב ברכות יום הולדת – שירנסקי מארח" (קוד: `tools/birthday-apps-script.gs`).
